# LINE版について

LINE版はWorkersでLINE Webhookを受け、LINE Messaging APIを使用して返信するBot
必要な情報はapi-hmbt.ast24.devのAPIサーバに問い合わせることで取得する

LINEBOT主体であるv4が /old-v4 にあるため、実装時はそれを参考にすることができる

## 機能

- 今日から1週間分の個人予定表の応答
- カフェメニューの応答
- web版へのリンク(※鯖側処理不要)

## Workersの処理

- LINE Webhook からイベントを受け取る
- 内部APIコールには環境変数のsystemロールのアクセストークンを使用
- ユーザのLINEIDを元にユーザIDを取得
  - ※このためにはAPIを拡張して GET /users でクエリパラメータを使って検索を行えるようにする(このEPはsystemロールのみ利用可能)
    - これはoidcのsubから検索する ※LINEIDはoidcのsubと同一である前提で動いてるが、万が一違った場合は連携トークンなどの別のアプローチに後で切り替える可能性もある
  - 無ければWeb版の連携設定ページURLを返信して、ここからアカウント作ったうえでLINE連携してねと案内する
- ユーザIDを元に個人予定表やカフェメニューの情報を取得
  - 個人時間割が設定されていない場合は、Web版の個人時間割設定ページURLを返信して、ここから個人時間割設定してねと案内する
- 予定表ならリッチメッセージ、カフェメニューならリッチメッセージか、存在するなら画像として返信する
- またv4からはLINEにCUDをさせないため、LINEはステートレスにでき、LINE専用の状態管理DBは不要になる

## APIの拡張

- GET /users EPを用意し、クエリパラメータで検索条件を指定できるようにする
  - クエリパラメータはLINEIDを想定
  - systemロールのみ利用可能とする

## リッチメニュー設定用のシェルスクリプト

- /binにLINE Messaging APIのリッチメニューを設定するためのシェルスクリプトを用意する
- リッチメニューは
  - 左上: 個人予定表
  - 左下: カフェメニュー
  - 右  : Web版へのリンク
  とする(※左の比率を右の比率の2倍にする)
- これを実行するとWorkersにリッチメニューが設定されるようにする
- なお、リッチメッセージの画像は同じディレクトリにあるものとする
- v4から大量に機能を削減したため、2ページ構成にしたりもしない

# V5拡張: "電車時刻機能"設計書

v4では電車の時刻を表示する機能があったが、代替アプリが多数存在するためv5では削除することにした。
…が、意外と需要があるかもしれないため復活させてみる。(自分も僅かに必要性を感じた場面があったし)

## 変更内容

- lib拡張
  - 教科列挙型に倣って時刻表列挙型を追加
    - 列挙型でidを定義したうえで、パラメータをそのidに対する情報というレコードで宣言する方式
    - 変わり得るとはいえ、現時点では学校周辺のみ固定にするつもりなので
    - 路線、駅、方面 を持つ
    - 現時点では以下の通り
      - JR鶴見線 鶴見小野駅 鶴見方面
      - JR鶴見線 鶴見駅 鶴見小野方面
      - JR京浜東北線 鶴見駅 東京方面
      - JR京浜東北線 鶴見駅 横浜方面
      - 京急本線 京急鶴見駅 品川方面
      - 京急本線 京急鶴見駅 横浜方面
      - 京急本線 花月総持寺駅 品川方面
      - 京急本線 花月総持寺駅 横浜方面
  - 今年度周辺の祝日リストを定数に追加
    - 本来なら祝日APIを叩いて動的に取得するべきだが、何年も運用するものではないため定数で十分と判断
    - ただし念の為この定数はサーバのみでアクセス可能とする
    - `https://holidays-jp.github.io/api/v1/2026/date.json`(2027年も同様のURLで取得可能)から取得してオブジェクト化
  - ホームのウィジェットに"次の電車"のバリアントを追加
    - パラメータで時刻表列挙型のバリアント名を配列で指定できる
      - 排他で 常に表示モード用配列 と 特定時刻で切り替えるモード用配列x2 を用意する
      - 後者の場合は切り替える時刻もパラメータで指定できるようにする
        - 例えば、午前中は登校方面、午後は下校方面の時刻表を表示するといった使い方を想定
    - 何件先まで表示するかもパラメータで指定できるようにする
    - "あとn分" か "hh:mm" かもパラメータで指定できるようにする
    - 編集はHomeのウィジェット編集画面で行う
    - デフォルトのパラメータは、12時切り替えで午前中は [`JR鶴見線 鶴見駅 鶴見小野方面`]、午後は [`JR鶴見線 鶴見小野駅 鶴見方面`, `JR京浜東北線 鶴見駅 横浜方面`, `JR京浜東北線 鶴見駅 東京方面`] を、3件先まで、"あとn分" で表示するものとする
- db拡張
  - 電車の時刻表を保存するテーブルを追加
  - libの時刻表列挙型のバリアント名を一意キーとして使う
  - 内容はJSONで保存する(クエリの必要性がないため、むしろ正規化による複雑化の方がデメリットになると判断)
  - ユーザui設定のテーブルに"次の電車"ウィジェットを追加するマイグレーションSQL(SQLが無理ならjsスクリプトでも)
    - 全ユーザのウィジェットの先頭にこのウィジェットを追加する
    - パラメータはデフォルトのものを入れる
- api拡張
  - 時刻表の内容を返すAPIを追加
  - パスで列挙型のバリアント名を受け取る
  - 続きのパスで対象の日付を受け取る
    - 祝日や土日を考慮して、実際の時刻表に解決する
  - 時と分が入れ子になったJSONを返す
- web拡張
  - Homeに時刻表表示用のウィジェットを追加
    - APIを叩いて次の電車までの時間を表示する
    - タップでタップされた時刻表を、時刻表っぽい形式(時ごとの分のリストの表)のポップアップで表示する
    - 時刻表の長さが画面の高さを越える場合は、スクロールできるようにすること
  - ui設定に次の電車ウィジェットの編集機能を追加
  - アップデート履歴ページに次のマイナーバージョンとしてこの機能追加を記載する
- hmbt拡張
  - 次の電車アクションを追加
    - 依存関係的にはあまり良くないが、webui設定を参照して表示する内容を決めることにする
      - じゃないとユーザに"使う電車"というプロパティを追加しなきゃいけなくなるし、そうなると切り替えるかや切替タイミングを持つ場所がおかしくなるため
      - 挙動は存在する全パラメータに従わせる(Webのみでしか実現できないパラメータは無いはず)
  - リッチメニュー設定スクリプトを変更し、横方向を3分割にしたうえで、判定領域を変更する
    - 左上: 予定表
    - 左下: 時間割
    - 中央上: 次の電車
    - 中央下: Web版リンク
    - 右上: メニュー
    - 右下: Web版リンク ※Web版リンクが2つあるのは意図的
  - ついでに、メニュー表示で画像しかない場合にはメッセージを送信しないようにする
    - "メニュー未登録、画像あり"とかが7つ並んでるのは邪魔すぎる
    - それと表示範囲を3日先までに変える
  - ここでのapiリクエストも、webのようにできる限りbatch化する(既存のコールも含む)
- bin実装
  - 旧実装を参考に、yahooからスクレイピングしてこのシステム用のJSONにし、それをSQLにするスクリプトを実装
    - 対象URLと時刻表IDは引数で指定
    - 開発中はとりあえずスクレイピングで取得する
      - 正規手段であるODPTは年の変わり目で使えないため
    - 公開時に正規のデータに切り替える
